# SafeVege

แอป Flutter สำหรับค้นหาร้านผักปลอดภัยและจัดการคำขอตรวจรับรองผัก ใช้แผนที่ OpenStreetMap (ฟรี 100% ไม่ต้องใช้ API Key)

## เริ่มใช้งาน

1. ติดตั้ง dependencies ด้วย `flutter pub get`
2. รันแอปด้วย `flutter run`

สามารถสร้างเว็บด้วย `flutter build web` ได้ทันที โดยแผนที่ OpenStreetMap และระบบค้นหาเส้นทาง OSRM จะพร้อมทำงานทันทีโดยไม่ต้องระบุ API Key ใดๆ

## ฟังก์ชันการทำงานหลัก

- **แผนที่ OpenStreetMap**: ค้นหาร้านผักปลอดภัย หมุดร้านค้า ปักหมุดพิกัด และแสดงเส้นทางขับรถจริง (OSRM)
- **ระบบผู้บริโภค / แขกทั่วไป**: ค้นหา ตรวจสอบใบรับรองผักปลอดสารพิษ และนำทางไปยังร้านค้า
- **ระบบร้านค้า (Farmer/Shop)**: จัดการโปรไฟล์ร้านค้า ยื่นคำขอตรวจผัก ติดตามนัดหมาย และดูใบรับรอง
- **ระบบผู้ดูแล (Admin)**: จัดการคำขอนัดหมายตรวจแปลงผัก บันทึกผลการตรวจ และออกใบรับรองดิจิทัล
