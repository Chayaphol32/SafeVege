# คู่มือผู้ใช้ SafeVege

วันที่จัดทำ: 17 ตุลาคม 2026

SafeVege ใช้ค้นหาร้านผักและดูผลตรวจหรือใบรับรองที่เผยแพร่แล้ว ร้านค้าสามารถส่งคำขอตรวจผักและติดตามงานของตน ส่วนผู้ดูแลรับผิดชอบการตรวจและการจัดการบัญชีตามสิทธิ์ คู่มือนี้อธิบายหน้าจอและขั้นตอนที่มีอยู่ในแอป ณ วันที่จัดทำ ข้อมูลที่เห็นจริงขึ้นอยู่กับรายการที่บันทึกไว้ สิทธิ์ของบัญชี การเผยแพร่ และการเชื่อมต่อระบบ

## 1. เริ่มต้นและเลือกบทบาท

จากหน้า “ยินดีต้อนรับสู่ SafeVege” เลือกทางเข้าที่ตรงกับการใช้งาน

| ผู้ใช้ | ทางเข้าบนหน้าต้อนรับ | งานหลัก |
| --- | --- | --- |
| ผู้เยี่ยมชมและผู้บริโภค | “เริ่มต้นใช้งาน (ผู้ใช้ทั่วไป)” | ค้นหาร้าน ดูข้อมูลที่เผยแพร่ ตรวจใบรับรอง และดูเส้นทาง โดยไม่ต้องสมัครสมาชิก |
| ร้านค้า | “เข้าสู่ระบบร้านค้า” | สมัครบัญชีร้านใหม่ เข้าสู่ระบบ แก้ไขข้อมูลร้าน และติดตามคำขอตรวจ |
| Inspector Admin (ผู้ตรวจการ) | “เข้าสู่ระบบผู้ดูแล” | จัดการคำขอ นัดหมาย บันทึกผลตรวจ ใบรับรอง และร้านค้า |
| Super Admin (ผู้ดูแลระบบขั้นสูง) | “เข้าสู่ระบบผู้ดูแล” | ดูภาพรวมงานตรวจ พร้อมจัดการบัญชี การตั้งค่า และประวัติการใช้งาน |

ผู้บริโภคใช้ส่วนสาธารณะเช่นเดียวกับผู้เยี่ยมชม แอปไม่มีขั้นตอนสมัครบัญชีผู้บริโภคในเส้นทางนี้ เมนูที่เห็นหลังเข้าสู่ระบบขึ้นอยู่กับบทบาทที่ได้รับจากระบบ

## 2. ผู้เยี่ยมชมและผู้บริโภค: ค้นหาและตรวจสอบร้าน

### 2.1 ค้นหาร้านจากหน้าหลักหรือแผนที่

1. แตะ “เริ่มต้นใช้งาน (ผู้ใช้ทั่วไป)” แล้วเลือกแท็บ “หน้าหลัก” หรือ “แผนที่” ที่แถบนำทาง
2. พิมพ์ชื่อร้าน ชนิดผัก หรือพื้นที่ในช่อง “ค้นหาร้าน ผัก หรือพื้นที่...” และดูรายการหรือหมุดร้านที่แสดง
3. หากต้องการดูร้านรอบตัว ให้เลือก “ใกล้ฉัน” หรือ “ร้านใกล้ฉัน” และอนุญาตให้แอปเข้าถึงตำแหน่งเมื่ออุปกรณ์ถาม หากไม่สะดวกให้ใช้การค้นหาชื่อหรือพื้นที่แทน
4. แตะร้านที่สนใจเพื่อเปิดรายละเอียด ตรวจชื่อ ที่อยู่ เบอร์โทร และผลตรวจที่แสดงก่อนเดินทาง

รายการสาธารณะแสดงเฉพาะร้านที่ระบบเปิดเผยแล้ว หากค้นหาไม่พบ ไม่ได้ยืนยันว่าร้านนั้นไม่มีอยู่ในระบบ ร้านอาจยังไม่ถูกเผยแพร่หรือไม่ตรงกับคำค้น

### 2.2 ตรวจใบรับรองและผลตรวจ

1. เปิดแท็บ “ใบรับรอง” หรือปุ่ม “ตรวจใบรับรอง” จากหน้าหลัก หน้ารายการใช้ชื่อ “ผลตรวจและใบรับรอง”
2. ค้นหาด้วยชื่อร้าน เลขใบรับรอง หรือชนิดผัก แล้วเลือกรายการที่ต้องการ
3. อ่านเลขใบรับรอง วันที่ออก วันที่หมดอายุ และชนิดผักที่เกี่ยวข้อง หากมีปุ่ม “เปิดใบรับรองจริง” ให้เปิดเอกสารเพื่อตรวจข้อมูลประกอบ
4. จากหน้ารายละเอียดร้าน สามารถใช้ปุ่ม “ใบรับรอง” เพื่อดูใบรับรองล่าสุดที่หน้านั้นแสดงได้ หากยังไม่มีเอกสาร หน้าจอจะแจ้งว่าร้านอยู่ระหว่างเตรียมเผยแพร่

ผลตรวจของผักแต่ละชนิดต้องดูร่วมกับใบรับรองที่เกี่ยวข้อง การเห็นชื่อร้านหรือสถานะคำขอเพียงอย่างเดียวไม่ใช่หลักฐานว่าใบรับรองยังใช้ได้ รายการสาธารณะของระบบจำกัดไว้ที่ใบรับรองซึ่งเผยแพร่และยังไม่หมดอายุ; หากไม่มีรายการ ให้ตรวจอีกครั้งภายหลังหรือติดต่อร้าน/ผู้ดูแล

### 2.3 ดูเส้นทางไปยังร้าน

จากหน้ารายละเอียดร้านหรือร้านในแท็บ “แผนที่” กด “นำทาง Maps” เพื่อเปิดเส้นทางไปยังพิกัดร้านในบริการแผนที่ภายนอก ตรวจจุดเริ่มต้นและจุดหมายในบริการนั้นก่อนเดินทาง หากเปิดแผนที่ภายนอกไม่ได้ ให้ตรวจว่าอุปกรณ์มีแอปหรือเบราว์เซอร์ที่รองรับและมีอินเทอร์เน็ต

แผนที่และเส้นทางต้องใช้การเชื่อมต่ออินเทอร์เน็ต ตำแหน่งอุปกรณ์อาจคลาดเคลื่อน ให้ตรวจจุดหมายและสภาพถนนจริงก่อนออกเดินทาง อย่าใช้งานหน้าจอขณะขับรถ

## 3. ร้านค้า: บัญชีและข้อมูลร้าน

### 3.1 สมัครสมาชิกร้านค้าและเข้าสู่ระบบ

1. จาก “เข้าสู่ระบบร้านค้า” เลือก “สมัครสมาชิกร้านค้าใหม่”
2. กรอก “ส่วนที่ 1: ข้อมูลเจ้าของร้าน” และ “ส่วนที่ 2: ข้อมูลร้านค้า” โดยช่องที่มีเครื่องหมาย `*` ต้องกรอก
3. ใน “ส่วนที่ 3: ตำแหน่งร้านค้าบนแผนที่” เลือก “เลือกตำแหน่งบนแผนที่” แล้ว “ยืนยันตำแหน่งนี้” หรือใช้ “ใช้ตำแหน่งปัจจุบัน” ตรวจพิกัดให้ตรงกับร้านหรือแปลงผักก่อนดำเนินการ
4. กรอกชื่อผู้ใช้ รหัสผ่านอย่างน้อย 12 ตัวอักษร และยืนยันรหัสผ่านใน “ส่วนที่ 4: ข้อมูลบัญชีผู้ใช้” แล้วกด “สมัครสมาชิก”
5. เมื่อเห็น “สมัครสมาชิกสำเร็จ” กด “เข้าสู่ระบบ” และลงชื่อด้วยชื่อผู้ใช้กับรหัสผ่านที่เพิ่งสมัคร

การสมัครสร้างบัญชีและร้าน แต่ไม่ได้ทำให้ร้านปรากฏต่อผู้บริโภคทันที การแสดงสาธารณะขึ้นอยู่กับผลตรวจ ใบรับรอง และการเผยแพร่โดยผู้ดูแล

### 3.2 แก้ไขข้อมูลร้านและพิกัด

หลังเข้าสู่ระบบ ให้เปิดแท็บ “ร้านค้าของฉัน” หรือหน้า “ข้อมูลร้านค้าของฉัน” กด “แก้ไขข้อมูลร้านค้า” แก้ชื่อร้าน ชื่อเจ้าของ เบอร์โทร หรือที่อยู่ตามที่หน้าจอเปิดให้แก้ หากต้องเปลี่ยนจุดบนแผนที่ให้กด “เปลี่ยนพิกัด” เลือกจุดที่ถูกต้องแล้ว “ยืนยันตำแหน่งนี้” สุดท้ายกด “บันทึกการเปลี่ยนแปลง” และตรวจข้อมูลที่แสดงอีกครั้ง

ตำแหน่งร้านที่บันทึกไว้ใช้เป็นค่าเริ่มต้นของคำขอตรวจใหม่ คำขอแต่ละฉบับเก็บที่อยู่และพิกัด ณ เวลาส่งคำขอ จึงควรตรวจจุดตรวจในแบบฟอร์มทุกครั้ง หากต้องการเปลี่ยนรหัสผ่าน ให้ใช้ “เปลี่ยนรหัสผ่านบัญชี” ในส่วน “ความปลอดภัยของบัญชี” และกด “ออกจากระบบ” เมื่อใช้เครื่องร่วมกับผู้อื่น

### 3.3 ส่งคำขอตรวจผัก

1. เปิดแท็บ “คำขอตรวจ” แล้วกด “ส่งคำขอใหม่” หรือเข้าหน้า “ส่งคำขอตรวจสอบ” จากหน้าหลักร้านค้า
2. กรอกชื่อผักอย่างน้อยหนึ่งรายการ กด “+ เพิ่มรายการผัก” เมื่อส่งหลายชนิด ห้ามปล่อยช่องว่างหรือใส่ชื่อผักซ้ำในคำขอเดียวกัน
3. ตรวจ “ตำแหน่งร้านและแปลงผัก” เลือก “เลือกตำแหน่งบนแผนที่” เพื่อใช้จุดตรวจครั้งนี้ หรือ “ใช้ตำแหน่งที่บันทึกไว้” เพื่อกลับไปใช้พิกัดร้าน
4. กด “ส่งคำขอตรวจสอบ” ตรวจจำนวนรายการในหน้าต่างยืนยัน แล้วกด “ยืนยันการส่ง”
5. หลังเห็น “ส่งคำขอตรวจสอบสำเร็จ” กด “ดูรายละเอียดคำขอ” หรือกลับมาดูในแท็บ “คำขอตรวจ”

การส่งสำเร็จหมายถึงระบบรับคำขอแล้ว ยังไม่ใช่ผลตรวจหรือการรับรอง

### 3.4 ติดตามนัดหมาย ผลตรวจ และใบรับรอง

เปิด “คำขอตรวจสอบทั้งหมด” เลือกคำขอเพื่อดู “รายละเอียดคำขอ” หน้านี้แสดงรายการผัก ที่อยู่สำหรับเข้าตรวจ ความคืบหน้า และวันนัดเมื่อผู้ดูแลกำหนดแล้ว เมื่อมีผลตรวจ ให้กด “ดูผลการตรวจและใบรับรอง” และอ่านผลแยกตามชนิดผัก หากยังไม่มีเอกสารใบรับรอง ให้รอการดำเนินการของผู้ดูแลหรือสอบถามผู้ดูแลโดยแจ้งหมายเลขคำขอ

## 4. ความหมายของสถานะคำขอ

| ป้ายสถานะในแอป | ความหมายที่ใช้ติดตามงาน | สิ่งที่ควรทำ |
| --- | --- | --- |
| “รอดำเนินการ” | ส่งคำขอแล้วและรอผู้ดูแลดำเนินการ | ตรวจรายการผักและรอการนัดหมาย |
| “นัดหมายแล้ว” | ผู้ดูแลบันทึกวันนัดตรวจ | เปิดรายละเอียดคำขอเพื่อตรวจวัน เวลา และหมายเหตุ |
| “เสร็จสิ้น” | มีผลตรวจบันทึกแล้ว หรือคำขอเข้าสู่ขั้นเผยแพร่แล้ว | เปิดผลตรวจและตรวจใบรับรองแยกต่างหาก |
| “ยกเลิกแล้ว” | คำขอถูกระบุว่ายกเลิก | ติดต่อผู้ดูแลหากไม่ทราบเหตุผล |

หน้าผู้ดูแลมีแท็บ “กำลังตรวจ” สำหรับกรองรายการ แต่ข้อมูลคำขอจากระบบปัจจุบันไม่ได้ถูกจัดเข้าแท็บนี้ จึงอาจไม่มีรายการให้เห็น แท็บนี้ไม่ใช่สถานะคำขอเพิ่มเติม ส่วนเส้นความคืบหน้าใน “รายละเอียดคำขอ” อาจแสดงข้อความ เช่น “ส่งคำขอแล้ว”, “รับคำขอแล้ว”, “นัดหมายวันตรวจ” และ “ตรวจสอบเสร็จสิ้น” เพื่อช่วยอ่านลำดับงาน ข้อความเหล่านี้ไม่ใช่สถานะเพิ่มเติมที่ร้านต้องเลือกเอง โดยเฉพาะ “เสร็จสิ้น” ไม่ได้ยืนยันว่าใบรับรองเผยแพร่แล้ว

## 5. Inspector Admin: ดำเนินงานตรวจ

บัญชี Inspector Admin ต้องได้รับสิทธิ์จากผู้ดูแลระบบ เข้าผ่าน “เข้าสู่ระบบผู้ดูแล” ด้วยชื่อผู้ใช้และรหัสผ่านของตน แถบหลักมี “ภาพรวม”, “คำขอตรวจ”, “ร้านค้า” และ “ประวัติ”

### 5.1 รับเรื่องและนัดหมาย

1. เปิด “คำขอตรวจ” หรือ “จัดการคำขอตรวจสอบ” ค้นหาชื่อร้านหรือหมายเลขคำขอ แล้วเปิด “รายละเอียดคำขอตรวจ”
2. ตรวจชื่อร้าน รายการผัก และสถานที่ตรวจ เมื่อคำขอยังรอดำเนินการ กด “กำหนดวันนัดตรวจแปลง”
3. เลือกวันและเวลา เติมหมายเหตุที่จำเป็น แล้วกด “ยืนยันวันนัดตรวจ” หากนัดหมายแล้วและต้องปรับ ให้ใช้ “แก้ไขวันนัดหมาย”

ร้านค้าจะเห็นวันนัดและหมายเหตุในรายละเอียดคำขอ ตรวจความถูกต้องกับร้านก่อนบันทึก

### 5.2 บันทึกผลและเผยแพร่ใบรับรอง

1. หลังนัดหมาย เปิดคำขอแล้วเลือก “บันทึกผลการตรวจแล็บ” เพื่อเข้าหน้า “บันทึกผลตรวจสอบ”
2. กำหนดผลของผักแต่ละชนิดตามเอกสารตรวจจริง: “ผ่าน”, “ไม่ผ่าน” หรือ “ตรวจซ้ำ” พร้อมรายละเอียดที่หน้าจอกำหนด
3. หากมีผักผ่านอย่างน้อยหนึ่งชนิด ต้องกรอกเลขใบรับรองตามเอกสารจริงและเลือกไฟล์ PDF หรือ JPG/JPEG ขนาดไม่เกิน 5 MB จึงจะบันทึกผลผ่านหน้านี้ได้ หากไม่มีผักชนิดใดผ่าน สามารถบันทึกผลโดยไม่แนบใบรับรอง
4. กด “บันทึกและเผยแพร่ผล” และยืนยันการบันทึก แล้วกลับไปตรวจรายละเอียดผลและใบรับรองของคำขอ

ปุ่ม “บันทึกร่าง” เก็บข้อมูลชั่วคราวในแอป ยังไม่ใช่การบันทึกผลลงระบบ การบันทึกผลโดยไม่มีใบรับรองทำได้เมื่อไม่มีผักชนิดใดผ่านเท่านั้น คำขออาจแสดง “เสร็จสิ้น” แต่จะไม่มีใบรับรองสาธารณะ แม้ปุ่มบันทึกจะเขียนว่า “บันทึกและเผยแพร่ผล” การเผยแพร่เกิดเมื่อมีผลที่ผ่านและแนบใบรับรองที่ใช้ได้ จึงควรตรวจรายการสาธารณะหลังทำงานเสร็จ หากทุกชนิดไม่ผ่านหรือให้ตรวจซ้ำ อย่าสื่อสารว่าร้านได้รับใบรับรอง

### 5.3 ร้านค้าและประวัติ

ใช้แท็บ “ร้านค้า” หรือ “จัดการร้านค้า” เพื่อดูข้อมูลร้านและดำเนินการตามปุ่มที่หน้าจอเปิดให้ ใช้แท็บ “ประวัติ” หรือ “ประวัติการตรวจสอบ” เพื่อตรวจงานที่ผ่านมา ก่อนแก้ไขหรือลบร้าน ตรวจประวัติคำขอและผลกระทบต่อข้อมูลที่เคยเผยแพร่ ระบบจำกัดการลบร้านที่มีประวัติการตรวจ

## 6. Super Admin: ดูภาพรวมและดูแลสิทธิ์

เมื่อเข้าสู่ระบบด้วยบัญชี Super Admin ให้เปิด “เมนูผู้ดูแลระบบขั้นสูง” จากหน้านี้ใช้ “ข้อมูลงานตรวจผักและร้านค้า” หรือ “เปิดแดชบอร์ดงานตรวจ” เพื่อเข้าถึงงานตรวจเช่นเดียวกับผู้ตรวจการ และใช้เมนูเฉพาะดังนี้

| เมนู | การใช้งาน |
| --- | --- |
| “จัดการบัญชีผู้ใช้” | ดูบัญชี สร้างบัญชีผู้ตรวจการด้วย “สร้างแอดมินตรวจผัก” เปิด/ปิดบัญชี และเปลี่ยนรหัสผ่านของผู้อื่น |
| “ตั้งค่าระบบ” | ดูและบันทึก “โหมดปิดปรับปรุงระบบ”, “ที่อยู่เว็บสาธารณะ (Public Web Base URL)” และ “อายุใบรับรองเริ่มต้น (วัน)” |
| “ประวัติการใช้งาน” | ตรวจรายการเปลี่ยนแปลงบัญชี รหัสผ่าน และการตั้งค่าที่ระบบบันทึก |

การเปลี่ยนรหัสผ่านของบัญชีอื่นทำให้การเข้าสู่ระบบเดิมของบัญชีนั้นสิ้นสุดลง เจ้าของบัญชีต้องลงชื่อใหม่ด้วยรหัสผ่านใหม่ ปุ่มเปลี่ยนรหัสผ่านในรายชื่อใช้กับบัญชีของตนเองไม่ได้ ระบบไม่ให้ปิดหรือเปลี่ยนบทบาท Super Admin ที่ยังใช้งานอยู่คนสุดท้าย

การสร้างบัญชีผู้ดูแลและการเปลี่ยนการตั้งค่าเป็นงานที่มีผลต่อผู้อื่น ให้ตรวจชื่อบัญชี บทบาท และค่าที่กรอกก่อนยืนยัน การมีเมนูตั้งค่าไม่ได้หมายความว่าทุกผลของการตั้งค่านั้นถูกบังคับใช้ครบทุกส่วนของแอป

## 7. แก้ปัญหาที่พบบ่อย

| อาการ | ตรวจสอบและดำเนินการ |
| --- | --- |
| ค้นหาร้านหรือใบรับรองไม่พบ | ลองค้นด้วยชื่อร้าน พื้นที่ เลขใบรับรอง หรือชนิดผักที่ถูกต้อง; รายการที่ยังไม่เผยแพร่หรือใบรับรองหมดอายุจะไม่อยู่ในผลสาธารณะ |
| แผนที่ว่าง ตำแหน่งไม่มา หรือเส้นทางไม่แสดง | ตรวจอินเทอร์เน็ต สิทธิ์ตำแหน่งของอุปกรณ์ และการเปิดบริการแผนที่ภายนอก แล้วลองอีกครั้ง; หากไม่ใช้ GPS ให้ค้นหาร้านด้วยชื่อหรือพื้นที่ก่อน |
| สมัครร้านค้าไม่สำเร็จ | ตรวจช่อง `*` รหัสผ่านอย่างน้อย 12 ตัวอักษร การยืนยันรหัสผ่าน และการเลือกพิกัด; อ่านข้อความผิดพลาดบนหน้าจอ |
| ส่งคำขอไม่ได้ | กรอกชื่อผักทุกแถว ลบแถวที่ไม่ใช้ ไม่ใส่ชื่อซ้ำ และตรวจจุดตรวจ/การเชื่อมต่อก่อนส่งใหม่ |
| เข้าสู่ระบบไม่ได้หรือลืมรหัสผ่าน | ตรวจชื่อผู้ใช้และรหัสผ่าน; หากยังเข้าไม่ได้ ให้ติดต่อ Super Admin เพื่อเปลี่ยนรหัสผ่าน ไม่มีขั้นตอนกู้คืนด้วย OTP ในแอป |
| เห็น “ไม่มีสิทธิ์เข้าถึงเมนูนี้” | ใช้บัญชีที่ได้รับบทบาทตรงกับเมนู หรือขอให้ Super Admin ตรวจสิทธิ์และสถานะบัญชี |
| คำขอ “เสร็จสิ้น” แต่ไม่พบใบรับรองสาธารณะ | เปิดผลของคำขอเพื่อตรวจว่ามีผักผ่านและมีใบรับรองหรือไม่; ให้ผู้ดูแลตรวจการเผยแพร่และวันหมดอายุ |
| โหลดข้อมูลไม่สำเร็จ | ตรวจการเชื่อมต่อแล้วใช้ “ลองอีกครั้ง” หรือปุ่มรีเฟรชที่มีในหน้านั้น หากยังเกิดซ้ำ ให้แจ้งผู้ดูแลพร้อมชื่อหน้าและเวลาที่พบปัญหา |

## 8. ข้อควรระวังในการใช้งาน

- ข้อมูลร้าน เบอร์โทร พิกัด ผลตรวจ และใบรับรองที่เผยแพร่อาจปรากฏแก่ผู้ใช้ทั่วไป ร้านค้าควรตรวจความถูกต้องก่อนส่งข้อมูล ผู้ดูแลควรตรวจเอกสารก่อนเผยแพร่
- ใบรับรองใช้กับร้าน ชนิดผัก และช่วงเวลาที่ระบุเท่านั้น ตรวจเลขใบรับรอง วันหมดอายุ และเอกสารจริงทุกครั้ง ไม่ควรตีความว่าผักทุกชนิดของร้านผ่านเพราะมีใบรับรองหนึ่งฉบับ
- เก็บรหัสผ่านเป็นความลับ ใช้รหัสผ่านเฉพาะบัญชี และออกจากระบบเมื่อใช้เครื่องร่วมกัน อย่าส่งรหัสผ่านหรือภาพหน้าจอที่มีข้อมูลบัญชีให้ผู้อื่น
- ผลแผนที่และเส้นทางเป็นข้อมูลช่วยเดินทาง ตรวจป้ายถนน ข้อจำกัดเส้นทาง และสภาพพื้นที่จริงเสมอ
- ข้อมูลสาธิตที่ใช้ในการพัฒนา รวมถึงเอกสารที่ระบุว่าเป็นตัวอย่าง ไม่ใช่หลักฐานรับรองสินค้าจริง
